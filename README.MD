# Blog App

A modern web application for creating, managing, and sharing blog posts. Built with ReactJS for the frontend and Spring Boot for the backend.

### Features

- User registration and authentication
- Create, edit, delete blog posts
- View blog posts by other users
- Responsive design for desktop and mobile
- RESTful API with Spring Boot backend
- MySql database integration
